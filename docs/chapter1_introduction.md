## 本文

Internet Relay Chat（IRC）は、インターネット上のテキストベースの通信プロトコルである。

*原文: Internet Relay Chat or IRC is a text-based communication protocol on the Internet.*

リアルタイムメッセージングを提供し、パブリック（公開）またはプライベート（非公開）のいずれかで行うことができる。

*原文: It offers real-time messaging that can be either public or private.*

ユーザーはダイレクトメッセージを交換したり、グループチャンネルに参加したりできる。

*原文: Users can exchange direct messages and join group channels.*

IRCクライアントはチャンネルに参加するためにIRCサーバーに接続する。

*原文: IRC clients connect to IRC servers in order to join channels.*

IRCサーバーは互いに接続してネットワークを形成する。

*原文: IRC servers are connected together to form a network.*

## 学習ポイント

1. **IRCの基本構造**: クライアント → サーバー → ネットワーク の階層
2. **本課題の範囲**: サーバー実装のみ（クライアント実装は対象外、サーバー間通信も対象外）
3. **Discordとの類似点**: チャンネルベースのグループチャット + DMの概念は同じ
