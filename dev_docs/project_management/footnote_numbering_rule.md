# 脚注ナンバリングルール

## 形式

```
[^xyz]  （3桁ゼロパディング、10刻み）
```

例: `[^010]`, `[^020]`, `[^030]`, ..., `[^150]`

## ルール

1. **3桁ゼロパディング**: 常に3桁で表記（010, 020, ... 100, 110, ...）
2. **10刻み**: 基本番号は10の倍数
3. **本文初出順**: 本文で最初に参照される順に番号を割り当て
4. **巻末定義順**: 巻末の脚注定義も番号順に並べる

## 挿入時のルール

同一セクション内に脚注を追加する場合:

| 状況 | 対応 |
|------|------|
| 060と070の間に1件追加 | `[^062]` を使用（2刻み） |
| 060と062の間に1件追加 | `[^061]` を使用（1刻み） |
| 大量追加 | 全体を振り直し |

## AIへの指示テンプレート

### 振り直し指示
```
脚注を本文初出順に振り直して。
形式: 3桁ゼロパディング、10刻み（010, 020, 030...）
```

### 追加時の指示
```
[^060]と[^070]の間に脚注を追加。番号は[^062]で。
```

## 自動振り直しスクリプト

`renumber_footnotes.py` を使用:

```bash
python renumber_footnotes.py input.md output.md
```
## 使い方:
確認（標準出力）
```bash
python renumber_footnotes.py irssi_handson_common.md
```

ファイル出力
```bash
python renumber_footnotes.py irssi_handson_common.md output.md
```
上書き（注意）
```bash
python renumber_footnotes.py file.md tmp.md && mv tmp.md file.md
```
## 補助ワンライナー（確認用）:

本文中の脚注参照を初出順に列挙
```bash
grep -oE '\[\^[0-9]+\]' file.md | grep -v '^\[' | awk '!seen[$0]++'
```
脚注定義の番号を列挙
```bash
grep -E '^\[\^[0-9]+\]:' file.md | grep -oE '\[\^[0-9]+\]'
```
